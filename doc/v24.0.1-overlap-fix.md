# v24.0.1: Text-Logo Overlap Bug Fix

## Problem Summary

**Issue**: Adaptive layout was being applied but logos still overlapped with Gemini-generated text.

**User Report**: "sometimes backend works correct sometimes its making an overlay issue"

## Root Cause Analysis

### The Math Error

From the failing generation logs:
```
[Spatial Verification] Text detected at 16.7% (should be below 36%)
[v24.0 Adaptive Layout] calculatedHeight: 226, availableHeight: 216
[v24.0 Adaptive Layout] ✅ Will apply adaptive row heights
```

**The Problem:**
- Text detected at: 16.7% from top
- Available safe space: 216px (15% of 1440px canvas)
- Adaptive layout returned: 226px (80+60+30+24+32)
- **226px > 216px = GUARANTEED OVERLAP** ❌

### Why It Was Inconsistent

| Gemini Text Position | Behavior | Result |
|---------------------|----------|---------|
| 25%+ (good) | No violations detected | ✅ Default heights work fine |
| 17% (bad) | Compressed mode (226px) | ❌ Overlaps (needs 216px) |
| <10% (worst) | Emergency mode | ✅ Would work (not implemented) |

### The Bug in Code

**File**: `lib/sharp/adaptive-logo-layout.ts:62`

**Before (WRONG):**
```typescript
// Total: 80 + 60 + 30 + 24 + 32 = 226px (fits in 214px with some compression)
if (headerHeight >= 214) {  // ← BUG: Returns 226px mode when only 216px available!
  return {
    mode: 'compressed',
    brandHeight: 80,
    vertical: 60,
    initiative: 30,
    // Total: 226px
```

**After (FIXED):**
```typescript
// Changed threshold to >= 226px and added super-compressed mode
if (headerHeight >= 226) {  // ← Now checks for actual required space
  return compressed mode (226px)
}
if (headerHeight >= 165) {  // ← NEW: Super-compressed for tight spaces
  return super-compressed mode (165px)
}
```

## The Fix

### 1. Fixed Threshold Check
- **Compressed mode**: Changed from `>= 214px` to `>= 226px`
- Now only returns compressed mode when there's actually enough space

### 2. Added Super-Compressed Mode
For cases where text is very close to top (16-17% violations):
- Brand: 60px (was 80px)
- Vertical: 45px (was 60px)
- Initiative: 20px (was 30px)
- Spacing: 10px (was 12px)
- Padding: 10px (was 16px)
- **Total: 165px** (fits in spaces as small as 165px)

### 3. Improved Emergency Mode
- Reduced brand height from 80px to 60px
- Reduced padding from 16px to 10px
- **Total: 80px** (for extreme cases)

### 4. Added Validation Logging
```typescript
if (!fitsInAvailableSpace) {
  console.error('[v24.0 Adaptive Layout] ❌ BUG: Calculated height exceeds available space!')
}
```

## Compression Levels

The system now has 4 compression levels:

| Level | Threshold | Brand | Vertical | Initiative | Total Height |
|-------|-----------|-------|----------|------------|--------------|
| **None** | >= 290px | 120px | 90px | 40px | 330px |
| **Standard** | >= 226px | 80px | 60px | 30px | 226px |
| **Super** | >= 165px | 60px | 45px | 20px | 165px |
| **Emergency** | < 165px | 60px | 0px (skip) | 0px (skip) | 80px |
