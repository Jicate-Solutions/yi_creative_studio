# Yi CreativeStudio - Admin & Super Admin Access Guide

**Document Version:** 1.0
**Last Updated:** January 21, 2026
**Platform:** Yi CreativeStudio - AI-Powered Brand Creative Generation

---

## Overview

Yi CreativeStudio has two levels of administrative access to manage the platform effectively:

1. **Organization Admin** - Manages a specific organization's settings, team, and credits
2. **Super Admin** - Platform-level access to manage all organizations, users, and system-wide settings

---

## 1. Organization Admin Access

### What is an Organization Admin?

An Organization Admin has full control over their specific organization within Yi CreativeStudio. They can manage team members, allocate credits, and configure organization settings.

### Access Level

- **Scope:** Single organization only
- **Route:** `/settings/admin`
- **Role Required:** `admin` role within the organization

### Key Features & Permissions

#### Team Management
- ✅ Invite new team members to the organization
- ✅ Remove team members from the organization
- ✅ Update member roles (admin, editor, viewer)
- ✅ View all team members and their activity

#### Credit Management
- ✅ View organization's credit balance
- ✅ Purchase additional credits
- ✅ View credit usage history and analytics
- ✅ Monitor team members' credit consumption

#### Organization Settings
- ✅ Update organization name and details
- ✅ Configure brand colors and preferences
- ✅ Manage organization logo library
- ✅ Set up vertical presets (for Yi chapters)

#### Creative Management
- ✅ View all creatives generated by the organization
- ✅ Delete organization creatives
- ✅ Export organization creatives
- ✅ Manage creative templates

### How to Access

1. Login to Yi CreativeStudio with your organization admin account
2. Click on **Settings** in the sidebar
3. Navigate to **Admin** section
4. You'll see the Organization Admin dashboard

### Who Should Have This Access?

- Organization leaders (Yi Chapter Presidents, Chairpersons)
- Team managers who need to manage members and credits
- Marketing heads responsible for brand consistency

## 2. Super Admin Access

### What is a Super Admin?

A Super Admin has platform-wide access to manage all organizations, users, credits, and system settings. This is the highest level of access in Yi CreativeStudio.

### Access Level

- **Scope:** Entire platform (all organizations)
- **Route:** `/super-admin`
- **Role Required:** `is_super_admin` flag in auth metadata

### Key Features & Permissions

#### Platform Dashboard (`/super-admin`)
- ✅ View platform-wide statistics (total users, organizations, creatives)
- ✅ Monitor real-time activity feed
- ✅ See recent purchases and transactions
- ✅ Track API usage and costs

#### User Management (`/super-admin/users`)
- ✅ View all users across all organizations
- ✅ Search and filter users
- ✅ Suspend/unsuspend user accounts
- ✅ Assign users to organizations
- ✅ Invite users to organizations
- ✅ Impersonate users (for support purposes)

#### Organization Management (`/super-admin/organizations`)
- ✅ View all organizations
- ✅ Create new organizations
- ✅ Update organization details
- ✅ Delete organizations
- ✅ View organization members and usage
- ✅ Manage organization subscriptions

#### Credit Management (`/super-admin/credits`)
- ✅ Allocate credits to any organization
- ✅ View all credit transactions across platform
- ✅ Monitor credit usage analytics
- ✅ Track credit purchases and allocations

#### Platform Analytics (`/super-admin/analytics`)
- ✅ Organization usage breakdown
- ✅ Platform-wide usage trends
- ✅ Format popularity analytics
- ✅ User engagement metrics

#### Billing & Revenue (`/super-admin/billing`)
- ✅ View platform revenue statistics
- ✅ Track top paying organizations
- ✅ Monitor subscription tiers
- ✅ Analyze revenue trends

#### Brand Assets (`/super-admin/brand-assets`)
- ✅ Manage platform-wide logo library
- ✅ Upload and organize brand logos
- ✅ Manage creative templates
- ✅ Set up default assets for new organizations

#### Audit Logs (`/super-admin/audit`)
- ✅ View all Super Admin actions
- ✅ Track who changed what and when
- ✅ Export audit logs for compliance
- ✅ Monitor security events

#### Team Management (`/super-admin/teams`)
- ✅ View all team members across all organizations
- ✅ Team statistics and analytics
- ✅ Monitor team permissions and roles

### How to Access

1. Login to Yi CreativeStudio with your Super Admin account
2. Navigate to `/super-admin` in the URL bar
3. You'll see the Super Admin dashboard

**Note:** Regular navigation may not show the Super Admin link. Directly visit the URL.

### Who Should Have This Access?

- **Platform Administrators** (JKKN technical team)
- **System Managers** responsible for platform maintenance
- **Senior Management** requiring oversight of all operations

⚠️ **Security Note:** Super Admin access should be granted sparingly and only to highly trusted personnel.

## Troubleshooting

### "Access Denied" Error

**Problem:** User sees "Access Denied" when accessing `/super-admin`

**Solutions:**
1. **Logout and Login Again** (most common fix)
   - Super Admin flag is stored in auth session
   - Session must be refreshed by logging out and back in

2. **Clear Browser Cache**
   - Clear cookies and cached data
   - Try in incognito/private mode

3. **Verify Database Flag**
   - Ask platform admin to verify `is_super_admin: true` in database
   - Check with:
     ```sql
     SELECT email, raw_app_meta_data->>'is_super_admin' as is_super_admin
     FROM auth.users
     WHERE email = 'your-email@jkkn.ac.in';
     ```

### Cannot See Super Admin Link in Navigation

**This is normal!**

Super Admin routes are protected and not shown in regular navigation. Access them directly:
- Type `/super-admin` in the URL bar
- Bookmark the page for easy access

### Permission Errors on Specific Actions

**Problem:** Can access Super Admin panel but certain actions fail

**Solutions:**
1. Check if your session has expired (logout and login)
2. Verify you're using the correct account with Super Admin access
3. Contact platform administrator if issues persist

## Security Best Practices

### For Super Admins

1. **Protect Your Credentials**
   - Use strong, unique passwords
   - Enable two-factor authentication (when available)
   - Never share your Super Admin account

2. **Audit Your Actions**
   - All Super Admin actions are logged
   - Review audit logs regularly
   - Be aware that changes are tracked

3. **Use Impersonation Wisely**
   - Only impersonate users for legitimate support purposes
   - End impersonation sessions immediately after resolving issues
   - Impersonation is logged and auditable

4. **Limit Access**
   - Don't grant Super Admin access unnecessarily
   - Regular organization admins don't need Super Admin access
   - Review Super Admin list quarterly

### For Organization Admins

1. **Manage Team Permissions Carefully**
   - Only grant admin role to trusted team members
   - Use viewer role for members who only need to view content
   - Use editor role for members who need to create content

2. **Monitor Credit Usage**
   - Regularly check credit consumption
   - Set up alerts for low credits
   - Review team member usage patterns

3. **Keep Organization Data Updated**
   - Maintain accurate organization information
   - Update brand colors and logos as needed
   - Remove team members who leave the organization

## Appendix: Technical Details

### Database Structure

**Super Admin Flag Location:**
- Table: `auth.users`
- Field: `raw_app_meta_data->>'is_super_admin'`
- Value: `true` (boolean)

**Organization Admin Role:**
- Table: `organization_members`
- Field: `role`
- Value: `'admin'` (enum)

### Access Control

**Super Admin Guard:**
- Middleware: `lib/middleware/super-admin-guard.ts`
- RPC Function: `is_current_user_super_admin()`
- All Super Admin routes protected by this guard

**Organization Admin Guard:**
- Middleware: `lib/middleware/org-admin-guard.ts`
- Checks: User must have `admin` role in `organization_members`

### Audit Logging

**Super Admin Actions Logged:**
- Table: `super_admin_audit_logs`
- Tracked: All create, update, delete operations
- Retention: Indefinite (for compliance)
