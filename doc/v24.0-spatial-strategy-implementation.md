# v24.0: Hybrid Spatial Strategy Implementation

## Problem Statement

Gemini consistently places text at ~18% from the top of event posters, regardless of prompt instructions. This causes the header logo bar (fixed at 24%) to overlay text content, creating unprofessional-looking posters.

## Root Cause

**Gemini's text placement is determined by training data, not prompt instructions.**

Gemini is an image generation model that generates images holistically based on learned patterns. It does NOT:
- Parse structured layout commands (XML, coordinates, zones)
- Execute positioning logic ("if Y < 518px, move down")
- Respond reliably to spatial constraints in prompts

The 18% text position is a learned default from its training data.

## Solution: Post-Generation Adaptation

Since prompting cannot control text placement, we **adapt AFTER generation** by:
1. Detecting where text actually appears
2. Calculating safe header height that won't overlap
3. Determining optimal logo layout mode (full/compressed/emergency)

## Implementation

### Phase 1: Text Detection Enhancement

**File**: `lib/sharp/text-zone-verifier.ts`

Enhanced text detection to accurately find the Y coordinate where text starts:

```typescript
interface TextDetectionResult {
  hasText: boolean
  firstTextRow: number  // Y coordinate of first detected text row
  textRowCount: number
}

function detectTextPatternWithPosition(buffer: Buffer, width: number, height: number): TextDetectionResult
```

**Helper Function**: `getSuggestedHeaderHeight()`
- Takes violations and canvas height
- Returns optimal header height in pixels and percentage
- Respects minimum header size (15%) for branding
- Adds safety buffer (3%) between logo bar and text

### Phase 2: Adaptive Logo Layout

**File**: `lib/sharp/adaptive-logo-layout.ts`

Calculates optimal logo layout mode based on available header height:

| Mode | Min Height | Brand Row | Vertical Row | Initiative Row | Use Case |
|------|-----------|-----------|--------------|----------------|----------|
| **Full** | 290px | 120px | 90px | 40px | Normal (text ≥25%) |
| **Compressed** | 214px | 80px | 60px | 30px | Tight space (text 18-24%) |
| **Emergency** | 112px | 80px | Skip | Skip | Very tight (text <18%) |

### Phase 3: Hybrid Spatial Strategy

**File**: `app/api/generate/route.ts` (line ~2152)

After image generation, before logo overlay:

```typescript
// Step 1: Detect violations
const violations = await detectTextInForbiddenZones(
  imageBuffer,
  logoStripZoneCoordinates.headerReservePercent,
  logoStripZoneCoordinates.footerReservePercent
)

// Step 2: Decision tree
if (actualTextY >= requiredSafeZone) {
  // ✅ PERFECT - No overlap, use static logo bar
  strategy = 'static'
} else if (actualTextY >= requiredSafeZone - 3) {
  // ⚠️ MINOR OVERLAP - Adjust header dynamically
  strategy = 'dynamic'
  finalHeaderHeight = getSuggestedHeaderHeight(violations, canvasHeight)
} else {
  // ❌ MAJOR OVERLAP - Fallback to dynamic positioning
  // (Regeneration not implemented yet - would waste API credits)
  strategy = 'dynamic'
  finalHeaderHeight = getSuggestedHeaderHeight(violations, canvasHeight)
}

// Step 3: Calculate adaptive layout mode
const adaptiveLayout = calculateAdaptiveLogoLayout({
  headerHeight: finalHeaderHeight,
  brandLogos: brandLogos.length,
  verticalLogos: verticalLogos.length,
  hasInitiative: !!enhanced4RowStrip.rows.initiative.text.trim()
})
```

## Benefits Over Previous Approaches

| Approach | Status | Issue |
|----------|--------|-------|
| XML spatial constraints | ❌ Failed | Gemini ignores XML layout meaning |
| Pixel-based positioning | ❌ Failed | Values rendered as visible text |
| Percentage safe zones | ❌ Failed | Gemini doesn't parse percentages |
| Instruction tags | ❌ Failed | Header still overlaps |
| **v24.0: Post-generation adaptation** | ✅ **Working** | Adapts to reality, not prompts |
