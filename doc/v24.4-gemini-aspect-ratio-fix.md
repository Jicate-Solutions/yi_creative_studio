# v24.4: Gemini Aspect Ratio Fix - Content-Only Generation

## Problem Solved

**Critical Error**: Gemini API rejected custom aspect ratio "1080:831" with error:
```
aspect_ratio must be one of '1:1', '2:3', '3:2', '3:4', '4:3', '4:5', '5:4', '9:16', '16:9', or '21:9'
```

## Root Cause

v24.3 attempted to generate at exact content-only dimensions (e.g., 1080 x 831 after removing 350px header and 259px footer), resulting in custom aspect ratio "1080:831" which Gemini doesn't support.

## Solution Architecture

### Step 1: Calculate Closest Gemini-Supported Aspect Ratio

Instead of passing custom aspect ratio to Gemini, we:
1. Calculate ideal content area dimensions (e.g., 1080 x 831)
2. Compute ideal aspect ratio (831/1080 ≈ 1.3:1)
3. Find **closest** Gemini-supported ratio from allowed list
4. Use that ratio for generation

**Example Calculation**:
```typescript
Ideal content area: 1080 x 831
Ideal aspect ratio: 1.3:1

Gemini ratios and distances:
- "4:3" = 1.333:1 → difference: 2.5% ✓ CLOSEST
- "5:4" = 1.25:1 → difference: 3.8%
- "3:2" = 1.5:1 → difference: 15.4%

Selected: "4:3"
```

### Step 2: Calculate Actual Gemini Dimensions

With selected aspect ratio (4:3), calculate what Gemini will return:
```typescript
Width: 1080 (keep constant)
Height: 1080 / (4/3) = 1080 * 0.75 = 810

Gemini will generate: 1080 x 810
```

### Step 3: Resize to Exact Content Area

After Gemini returns 1080 x 810, resize to exact content area:
```typescript
From: 1080 x 810 (Gemini output)
To: 1080 x 831 (exact content area needed)

Height stretch: 810 → 831 = 2.6% increase
(Barely noticeable distortion)
```

### Step 4: Expand to Full Canvas

Composite resized content onto full canvas with blank header/footer zones:
```typescript
Full canvas: 1080 x 1440
- Header zone: 0 - 350px (BLANK WHITE)
- Content zone: 350 - 1181px (RESIZED GEMINI OUTPUT)
- Footer zone: 1181 - 1440px (BLANK WHITE)
```

### Step 5: Overlay Logo Bars

Logo bars composite over blank zones (same approach as speaker photos):
- Header bar overlays at Y=0
- Footer bar overlays at Y=1181
- Content is NEVER overlapped because logo bars only cover blank zones

## Key Implementation Details

### File: `app/api/generate/route.ts`

**Lines 1640-1736**: Content-Only Dimension Calculation
```typescript
// Calculate ideal content area
const idealContentHeight = height - headerHeight - footerHeight
const idealContentWidth = width
const idealAspectRatio = idealContentWidth / idealContentHeight

// Find closest Gemini-supported ratio
const geminiAspectRatios = {
  '1:1': 1.0,
  '4:3': 1.333, // ✓ Typically closest
  '3:2': 1.5,
  // ... all supported ratios
}

let closestRatio = '4:3'
let closestDifference = Math.abs(geminiAspectRatios['4:3'] - idealAspectRatio)

for (const [ratio, value] of Object.entries(geminiAspectRatios)) {
  const difference = Math.abs(value - idealAspectRatio)
  if (difference < closestDifference) {
    closestDifference = difference
    closestRatio = ratio
  }
}

// Calculate actual Gemini output dimensions
const [ratioWidth, ratioHeight] = closestRatio.split(':').map(Number)
const geminiAspectValue = ratioWidth / ratioHeight
contentOnlyWidth = idealContentWidth
contentOnlyHeight = Math.round(contentOnlyWidth / geminiAspectValue)

// Create format for Gemini with supported aspect ratio
selectedFormat = {
  ...selectedFormat,
  width: contentOnlyWidth,
  height: contentOnlyHeight,
  aspectRatio: closestRatio, // e.g., "4:3"
}
```

**Lines 2006-2078**: Expansion and Resize Logic
```typescript
// Get actual Gemini output dimensions
const geminiWidth = contentMetadata.width || contentOnlyWidth
const geminiHeight = contentMetadata.height || contentOnlyHeight

// Calculate exact content area needed
const exactContentHeight = originalFormat.height - headerHeight - footerHeight
const exactContentWidth = originalFormat.width

// Resize Gemini output to exact content area
let resizedContent: any = imageBuffer
if (geminiWidth !== exactContentWidth || geminiHeight !== exactContentHeight) {
  const resized = await Sharp(imageBuffer)
    .resize({
      width: exactContentWidth,
      height: exactContentHeight,
      fit: 'fill', // Stretch to fill (typically <3% distortion)
    })
    .toBuffer()
  resizedContent = resized as any
}

// Create full canvas with blank zones
finalImageBuffer = await Sharp({
  create: {
    width: originalFormat.width,
    height: originalFormat.height,
    channels: 4,
    background: { r: 255, g: 255, b: 255, alpha: 1 },
  },
})
  .composite([
    {
      input: resizedContent,
      top: logoStripZoneCoordinates.headerHeight,
      left: 0,
    },
  ])
  .png()
  .toBuffer()
```

## Why This Works

1. **Gemini Happy**: Receives only supported aspect ratios (e.g., "4:3")
2. **Content-Only Principle Maintained**: Gemini generates WITHOUT forbidden zones existing
3. **Minor Distortion**: Typical resize is <3% (imperceptible)
4. **100% Coverage**: No gaps in content area
5. **Zero Overlaps**: Logo bars overlay blank zones only
