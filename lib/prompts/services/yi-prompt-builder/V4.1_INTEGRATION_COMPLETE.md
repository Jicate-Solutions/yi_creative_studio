## What Happens Now

Every time a user creates an event poster:

1. **Form submitted** → `/api/generate` endpoint
2. **buildOptions constructed** → Includes v4.1 configs (auto-enabled)
3. **Format builder called** → `buildEventPosterPrompt()`
4. **v4.1 contexts built** → `buildAllV41Contexts()` generates narrative sections
5. **Prompt assembled** → v4.1 contexts injected into final prompt
6. **Sent to Gemini** → AI receives complete instructions including:
   - White header band for logos (12% height)
   - Centered headlines, left-aligned details
   - Text shadows for legibility
   - Standardized footer with chapter branding
   - Event details card with icons
7. **Image generated** → Matches reference Yi designs
8. **Post-processing** → Logos overlaid in clean header band
