## ✨ Key Features

### 1. Dynamic Context Generation
All v4.1 contexts are **parameter-driven** and respond to input data:

**Example 1: Chennai Chapter**
```typescript
Input: { organizationContext: { name: "Chennai" } }
Output: Hashtag: #YICHENNAI, Social: @yi.chennai
```

**Example 2: Bangalore Chapter**
```typescript
Input: { organizationContext: { name: "Bangalore" } }
Output: Hashtag: #YIBANGALORE, Social: @yi.bangalore
```

**Example 3: Event Without Date/Time**
```typescript
Input: { eventDate: undefined, eventTime: undefined }
Output: Event details card DISABLED (not generated)
```

### 2. Conditional Enabling
Features automatically enable/disable based on data availability:
- **Header band:** Always enabled for event posters
- **Footer:** Always enabled with auto-generated chapter details
- **Event details card:** Only enabled if date/time/venue provided
- **Text shadows:** Always enabled for headlines
- **Alignment:** Always enforced (center headlines, left details)

### 3. Backward Compatibility
- All v4.1 fields are **optional** in `EnhancedBuildOptions`
- Existing code works unchanged
- No breaking changes
- Graceful degradation if v4.1 configs not provided

## 🎓 Technical Architecture

### Context Generation Flow
```
User fills form
    ↓
POST /api/generate
    ↓
buildOptions constructed with v4.1 configs
    ↓
buildEventPosterPrompt() called
    ↓
buildAllV41Contexts() generates narrative sections
    ↓
v4.1 contexts injected into final prompt
    ↓
Prompt sent to Gemini 2.5 Flash Image
    ↓
AI generates image following v4.1 instructions
    ↓
Sharp post-processing overlays logos in header band
    ↓
Final image returned to user
```

### Narrative-Based Prompting
v4.1 uses **natural language descriptions** instead of technical CSS:

✅ **Good (v4.1 approach):**
- "centered horizontally for maximum impact"
- "white rounded rectangle container"
- "subtle dark shadow for enhanced legibility"

❌ **Bad (avoided):**
- "text-align: center; font-size: 48px;"
- "border-radius: 12px; background: #FFFFFF;"
- "text-shadow: 0 2px 4px rgba(0,0,0,0.3);"

**Why?** Gemini renders technical CSS terms as visible text in the image. Natural language works better for AI image generation.
