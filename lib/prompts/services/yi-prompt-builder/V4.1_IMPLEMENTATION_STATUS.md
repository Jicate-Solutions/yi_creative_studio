## 💡 Design Philosophy

### Narrative Over Technical

✅ **Good:** "centered horizontally for maximum impact"
❌ **Bad:** "text-align: center; font-size: 48px"

**Why?**
- Gemini renders technical CSS as visible text
- AI understands design intent better than pixels
- Flexible adaptation to different aspect ratios
- Matches v3.6 prompt sanitization approach

### Backward Compatibility

- ✅ All v4.1 parameters optional
- ✅ Existing behavior unchanged when v4.1 configs absent
- ✅ Incremental adoption (format by format)
- ✅ No breaking changes to existing APIs

## 🚀 Usage Example

```typescript
// In a format builder (event-poster.ts)

import { buildAllV41Contexts } from '../context-helpers-v41'

// Build v4.1 contexts
const v41Contexts = buildAllV41Contexts({
  textAlignment: {
    headlines: 'center',
    details: 'left',
    footer: 'center',
  },
  textShadow: {
    enabled: true,
    roles: ['headline', 'subheadline'],
    intensity: 'subtle',
  },
  headerLogoBand: {
    enabled: true,
    heightPercent: 12,
    secondaryLogos: !!options.verticalId,
  },
  footerStyle: {
    enabled: true,
    heightPercent: 10,
    leftSection: 'standard_yi',
    rightSection: 'partner_logo',
    chapterDetails: {
      chapterName: options.organizationContext?.name || 'Kanniyakumari',
    },
  },
  footerContext: options.footerContext,
  eventDetailsCard: {
    enabled: !!(data.eventDate || data.eventTime || data.venue),
    position: 'bottom-center',
    includeIcons: true,
  },
  eventData: {
    date: data.eventDate,
    time: data.eventTime,
    venue: data.venue,
  },
})

// Inject into prompt
return `
A VISUALLY STUNNING event poster...

${existingContexts}

${v41Contexts}

POSTER DESCRIPTION:
...
`
```
